# CloudPass

A bus pass management web application built using Flask and MySQL.

## Features
- User registration and login
- View available bus pass plans
- Book bus passes
- View previously booked passes
- Session-based login and logout

## Technologies Used
- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript

## Setup
1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install dependencies:

   pip install -r requirements.txt

4. Create a `.env` file with your database configuration and `FLASK_SECRET_KEY`.
5. Run the application:

   python app.py

6. Open `http://127.0.0.1:5000/` in your browser.
